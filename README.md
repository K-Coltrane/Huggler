# Huggler Construction Website

A responsive one-page website for Huggler Construction, a general contractor in
Fortuna, California.

## Files

- `index.html` - page content, SEO metadata, and business information
- `styles.css` - responsive visual design and layout
- `script.js` - before/after gallery slider, current year, and quote-form helper
- `assets/` - starter SVG project visuals that can be replaced with real photos

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.
